# Ve mijo solo debes ejutar estas ciositas pa que lo coras y veas el componente XD



```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```



Start por el puerto `http://localhost:3000`:

```bash
# npm
npm run dev

# pnpm
pnpm dev

# yarn
yarn dev

# bun
bun run dev
```
